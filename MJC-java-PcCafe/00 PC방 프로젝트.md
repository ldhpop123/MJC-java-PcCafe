# PC방 관리 프로그램

Java Swing + MySQL 대학교 과제. 한 JVM 안에서 **관리자 창 1개**와 **게스트 창 N개**를 띄운다.

## 기획
- [[개요]] — 개발 환경, 핵심 요약
- [[시스템 구조]] — BaseFrame 상속, 창 생성 방식
- [[기능 명세]] — 게스트 / 관리자 기능과 우선순위
- [[스레드 설계]] — 좌석별 TimerThread, 시간 저장 시점
- [[채팅 설계]] — 객체 참조로 메시지 전달
- [[DB 설계]] — E-R 다이어그램, 테이블, CRUD 매핑
- [[화면 설계]] — 화면 설계도(SVG), Figma 가져오기
- [[패키지 구조]] — 클래스 배치
- [[개발 순서]] — 진행 체크리스트
