# 개발 순서

- [x] DB 스키마(`schema.sql`) 작성, `DBUtil` 작성 → [[DB 설계]]
- [x] `DBUtil` 실제 연결 확인 (MySQL 실행 + `db.properties`)
- [x] `BaseFrame` / `AdminFrame` / `GuestFrame` 뼈대, 게스트 추가 버튼 → [[시스템 구조]]
- [x] 회원가입 / 로그인 (`MemberDAO`)
- [x] 좌석 선택 + `TimerThread`, 창 닫을 때 시간 저장 → [[스레드 설계]]
- [x] 관리자 좌석판, 시간 추가 / 차감, 강제 종료
- [x] 시간 추가 구매 (`time_product`, `payment`)
- [x] 채팅 → [[채팅 설계]]
- [x] 메뉴 관리 탭 (`MenuPanel`)
- [x] 음식 주문 (게스트) / 주문 탭 (`OrderPanel`): 완료 처리, 취소 시 재고 복구 + 환불 기록
- [x] 회원 관리 탭 (`MemberPanel`): 검색, 수정, 삭제
- [x] 매출 탭 (`SalesPanel`): 오늘 시간 / 음식 / 합계
- [x] 관리자 로그인 (`AdminLoginFrame`, `member.is_admin`)
- [ ] GUI 실제 실행 테스트 → [[00 발표 개요]]의 시연 시나리오대로
- [ ] 보안: 비밀번호 해시, 초기 계정, 좌석판 이름 HTML 이스케이프

> DAO는 DB에 직접 붙여서 테스트 완료 (로그인, 검색, 재고 차감/부족, 주문 JOIN, 매출 합계, 환불). 화면(GUI)은 아직 직접 눌러보지 않았다.
