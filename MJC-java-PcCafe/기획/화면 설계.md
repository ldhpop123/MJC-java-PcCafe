# 화면 설계

화면 설계도는 저장소의 `design/` 폴더에 SVG로 있다. 크기와 배치는 실제 코드 기준이다(관리자 창 1000×650, 게스트 창 420×520). 화면마다 빨간 번호와 "구성 요소" 범례가 붙어 있다.

| 파일 | 화면 | 클래스 |
| --- | --- | --- |
| `00_화면_흐름도.svg` | 전체 화면 이동 + 창끼리 호출 | - |
| `01_관리자_로그인.svg` | 관리자 로그인 | `AdminLoginFrame` |
| `02_관리자_좌석.svg` | 좌석판, 시간 ±, 강제 종료, 채팅 | `AdminFrame` |
| `03_관리자_회원관리.svg` | 회원 검색 / 수정 / 삭제 | `MemberPanel` |
| `04_관리자_메뉴관리.svg` | 메뉴 CRUD | `MenuPanel` |
| `05_관리자_주문.svg` | 주문 완료 / 취소 | `OrderPanel` |
| `06_관리자_매출.svg` | 오늘 매출 | `SalesPanel` |
| `07_게스트_로그인.svg` | 로그인 + 좌석 선택 | `GuestFrame` (login 카드) |
| `08_게스트_사용중.svg` | 남은 시간, 채팅, 버튼 | `GuestFrame` (using 카드) |
| `09_회원가입.svg` | 회원가입 | `SignUpDialog` |
| `10_팝업_시간구매.svg` | 요금제 선택 | `JOptionPane.showInputDialog` |
| `11_팝업_음식주문.svg` | 메뉴 + 수량 | `JOptionPane.showConfirmDialog` |

## Figma 파일
https://www.figma.com/design/opq8v7G3k3Y0DYlBf94zP8

- 1줄: 흐름도, 관리자 로그인 / 2줄: 관리자 탭 5개 / 3줄: 게스트 화면과 팝업
- 글꼴은 Figma에 있는 Noto Sans KR로 바꿔서 넣었다. 흐름도 화살촉은 Figma 선 끝 화살표로 다시 달았다.

## Figma로 직접 가져오기 (SVG가 바뀌었을 때)
1. Figma 데스크톱 앱에서 새 디자인 파일 만들기
2. Finder에서 `design/` 폴더의 SVG를 모두 선택해 캔버스로 끌어다 놓기
3. 들어온 SVG는 도형과 글자가 **편집 가능한 레이어**로 들어온다. 레이어 이름은 `JButton 로그인`, `좌석 3`, `JTable (JScrollPane)`처럼 Swing 부품 이름으로 되어 있다.
4. 각 화면을 선택 → `Ctrl+Alt+G`(Mac: `⌥⌘G`)로 프레임으로 감싸면 정리하기 좋다.

> [!note] 글꼴
> 글꼴은 Apple SD Gothic Neo로 지정했다. Windows에서 열면 Figma가 다른 글꼴로 바꿔서 보여줄 수 있다.

## 설계도 다시 만들기
화면이 바뀌면 `design/gen_design.py`를 고친 뒤 실행한다.

```bash
python3 design/gen_design.py design
```
